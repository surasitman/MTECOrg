สรุปแนวทาง

  • ย้ายเป็นทีม ไม่ย้ายเป็นคน — ทุกหน่วยงานย้ายทั้งงาน (RISD, SAPD, CS, IBL, BAM) งานจึงไม่ขาดมือ และลดแรงต้านจากการแยกคนออกจากทีม
  • 2 ระลอก — มี.ค. 2570 เปลี่ยนภายในฝ่ายก่อน (งานทะเบียนสัญญากลาง, รวม GAD+SEC) เพราะ ผอ.ฝ่ายสั่งการได้เอง · เม.ย. 2570 ทีมเสมือนข้ามฝ่าย
  • เงื่อนไขก่อนย้ายทางการ — คนที่ภาระเกินต้องตกลงงานที่หยุดหรือโอนออกก่อน และงานที่อยู่กับคนเดียวต้องมีคู่มือกับผู้สำรอง
  • ผู้บริหารต้องตัดสินใจ ตำแหน่ง ผอ.ฝ่าย G2 และหัวหน้างานที่ว่างภายใน ส.ค. 2570 ก่อนคำสั่งย้ายทางการเดือน ต.ค. 2570
  • ประเด็นที่มักพลาด — ต้องกำหนดให้ชัดว่าใครประเมินผลงานรอบปี 2570 ของคนในทีมเสมือน และต้องโอน cost center กับสิทธิ์อนุมัติในระบบพร้อมคำสั่ง

สรุปแนวทาง

  • ย้ายงาน ไม่ย้ายคน — ทุกคนสังกัดเดิม ผู้ประเมินผลงานคนเดิม ใช้คำสั่งมอบหมายงานตามอำนาจของผู้จัดการงาน ผอ.ฝ่าย หรือ ผอ.ศว.
  • ภายในก่อน ข้ามฝ่ายทีหลัง — จับคู่คนที่ภาระเกินกับคนในงานเดียวกันที่ Job Code เดียวกันก่อน แล้วจึงข้ามงานในฝ่าย และยืมตัวข้ามฝ่ายเป็นลำดับสุดท้าย
  • งานที่ไม่มีใครรับได้ต้องลดที่ต้นเหตุ — ส่วนใหญ่เป็นงานเบิกจ่าย/จัดซื้อของ RPS ซึ่งเป็น Pilot หลักสูตร AI อยู่แล้ว จึงใช้ผล Pilot ลดชั่วโมงก่อนคิดเรื่องเพิ่มคน
  • ผู้สำรองทุกงานที่อยู่กับคนเดียว — จับคู่ Buddy ในงานเดียวกัน ใช้เวลาฝึก 40–120 ชม. ต่อคู่ ส่วนใหญ่อยู่ที่ห้องปฏิบัติการ TSMA
  • งานซ้ำซ้อนใช้คณะทำงาน — แต่งตั้งคณะทำงานข้ามฝ่ายพร้อมหน่วยงานเจ้าภาพและ RACI แทนการรวมหน่วยงาน

ผังองค์กรและหน่วยงานเหมือนเดิมทุกอย่าง แต่เปิดให้บุคลากร ย้ายตัวไปทำงานในหน่วยงานที่ขาดคน ได้ (Internal mobility) ทั้งโดยสมัครเองและได้รับเชิญ ตอนนี้มี — หน่วยงานที่ขาดคน รวม — อัตรา จากข้อมูล JA จับคู่ผู้ย้ายที่ทีมเดิมรับงานแทนได้ — คน ลดชั่วโมงเกินได้ — ชม./ปี ที่เหลืออีก — อัตรา เปิดรับสมัครย้ายภายในก่อนขออัตราใหม่

กติกาการย้ายงาน

  • สมัครใจ — ผู้ย้ายเลือกเองหรือตอบรับคำเชิญ ไม่ลดตำแหน่งหรือค่าตอบแทน และกลับต้นสังกัดได้ภายในช่วงทดลอง 3 เดือน
  • ไม่สร้างปัญหาใหม่ — ย้ายได้เมื่อเพื่อนร่วมทีมเดิมที่ทำงานใกล้เคียงกันรับงานแทนได้โดยไม่เกิน 1,800 ชม./ปี และไม่ดึงคนจากหน่วยงานที่ขาดคนเอง
  • ไม่ย้ายเจ้าของงานคนเดียว — คนที่ทำงานคนเดียว ≥ 500 ชม./ปี ต้องมีผู้สำรองก่อน (ดูแท็บย้ายงาน)
  • ตรงงานก่อน — Job Code เดียวกันย้ายได้เลย ส่วน Job Code ใกล้เคียงต้องฝึกงานคู่ 3 เดือน และนับประสิทธิภาพปีแรก 70%
  • สังกัดตามงานที่ทำ — เมื่อย้ายถาวรให้ปรับ JD, OKR และผู้ประเมินผลงานตามหน่วยงานใหม่ ผังองค์กรไม่เปลี่ยน
